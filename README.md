# Автоматизированная система контроля знаний в области интернет-технологий

⚠️ **СТАТУС ПРОЕКТА: ЗАВЕРШЕН / АРХИВНЫЙ**  
*Проект разрабатывался в качестве практической части дипломной работы. Программное обеспечение было успешно доведено до полной готовности, продемонстрировано на защите и использовалось для аттестации студентов. На текущий момент проект находится в статусе поддержки «как есть».*

---

## 📌 Описание проекта
Данное программное обеспечение представляет собой специализированную платформу для проведения тестирования и контроля уровня знаний студентов или сотрудников в сфере веб-разработки и интернет-технологий. Система полностью автоматизирует весь цикл проверки знаний и ведения отчетности.

### Основной функционал:
* **Модуль тестирования:** Интерактивное прохождение тестов по различным темам интернет-технологий.
* **Автоматическая проверка:** Мгновенный расчет результатов и выставление оценки на основе заложенных критериев.
* **Личные профили пользователей:** Сохранение учетных данных пользователей системы.
* **Журнал успеваемости:** Архивация результатов тестирования, фиксация набранных баллов и сохранение оценок в привязке к профилю пользователя.

## 💎 Особенности реализации
* **Полная готовность:** В отличие от большинства учебных прототипов, данное ПО является полностью завершенным и рабочим продуктом.
* **Связная архитектура:** Реализована полноценная реляционная структура данных «Пользователь ↔ Пройденный тест ↔ Оценка».
* **Автономность:** Система не требует сложной внешней инфраструктуры и готова к локальному или серверному развертыванию.
